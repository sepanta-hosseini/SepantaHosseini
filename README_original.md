# Sepanta Digital Profile

## Files
- `index.html`: page structure
- `style.css`: all visual styles and animations
- `script.js`: contact-card download and current year
- `assets/profile.jpg`: profile photo

## Run locally
Open `index.html` in a browser.

## Before publishing
1. Confirm the email address in `index.html`. It currently uses the address exactly as provided: `hosseinisepanta05@gmial.com`.
2. Replace the QR placeholder with your own image when ready. Put it at `assets/qr-code.png` and update the QR section in `index.html` if you want it displayed.
3. Add your personal website URL when it exists.

## GitHub Pages
Push the contents of this folder to a GitHub repository. In the repository, open Settings -> Pages, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
